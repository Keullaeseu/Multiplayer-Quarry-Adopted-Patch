# Multiplayer Quarry [Adopted] Patch

A RimWorld Multiplayer compatibility patch for [Quarry [Adopted]](https://steamcommunity.com/sharedfiles/filedetails/?id=2007576583).

This mod is intended to synchronize Quarry [Adopted]-related data and behavior between multiplayer clients when using RimWorld Multiplayer.

## Features

- Adds multiplayer compatibility for Quarry [Adopted].

## Requirements

- RimWorld
- Harmony
- RimWorld Multiplayer
  - [GitHub version](https://github.com/rwmt/Multiplayer) or [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=2606448745) version
- [Quarry [Adopted]](https://steamcommunity.com/sharedfiles/filedetails/?id=2007576583)

## Installation

### Steam Workshop

Subscribe to the required mods and add them to your RimWorld mod list in the following order:

1. Harmony
2. Core
3. Royalty, Ideology, Biotech, and Anomaly, if applicable
4. RimWorld Multiplayer
5. Quarry [Adopted]
6. [Multiplayer Quarry [Adopted] Patch](https://github.com/Keullaeseu/Multiplayer-Quarry-Adopted-Patch/releases/latest)

### Manual Installation

1. Download the latest release from the [**Releases**]((https://github.com/Keullaeseu/Multiplayer-Quarry-Adopted-Patch/releases/latest)) section.
2. Extract the mod folder into your RimWorld `Mods` directory.
3. Enable the required mods in RimWorld.
4. Use the recommended load order listed above.
5. Make sure every multiplayer player has the same mod list, configuration, and load order.

## Multiplayer Usage

All players should have the following mods installed and enabled:

- RimWorld Multiplayer
- Quarry [Adopted]
- Multiplayer Quarry [Adopted] Patch

The host and all connected clients should use the same:

- RimWorld version
- RimWorld Multiplayer version
- Quarry [Adopted] version
- Multiplayer Quarry [Adopted] Patch version
- Mod configuration
- Mod load order

For the best results, every player should use the same game version, mod versions, configuration files, and load order.

## Compatibility

This mod is intended to provide multiplayer compatibility for Quarry [Adopted].

It does not replace:

- RimWorld Multiplayer
- Quarry [Adopted]

## Known Limitations

- Compatibility may be affected by future RimWorld updates.
- Compatibility may be affected by future updates to RimWorld Multiplayer or Quarry [Adopted].
